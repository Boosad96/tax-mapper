Sources & how we verify

Accuracy over completeness. A mapping ships as “verified” only when at least two independent published sources agree on it. Blog tables alone are not enough — and where sources disagree, the mapping is shown as unresolved or left out entirely, with the reason written down here.

Official sources

  • CBDT concordance — Form 121: the official section-wise concordance between the 1961 Act and the 2025 Act. (incometax.gov.in)
  • E-filing portal comparison utility: “Utility to check provisions of Income-tax Act, 1961 vis-à-vis Income-tax Act, 2025” — a two-way lookup, plus a Rules utility (1962 vs 2026) and a forms-mapping utility for the reduced 190-form set. (incometax.gov.in)

Known conflicts we resolved by majority

  • Section 16 (standard deduction): majority says Section 19; one tracker says 22. Tool uses 19.
  • Section 24 (house property): majority says Section 22; one older tracker says 20. Tool uses 22.
  • 44AD/44ADA/44AE (presumptive taxation): majority says Section 58; one source says 61. Tool uses 58.
  • Section 234A (late filing interest): majority says Section 423; TaxGuru notes a source saying 430. Tool uses 423.
  • Form 26AS: three sources say Form 168; one says Form 132. Tool uses 168.
  • Form 27EQ: majority says Form 143; TDSGuru says 144A. Tool uses 143.
  • TDS code 1012 (194LA): threshold ₹5,00,000 under the 2025 Act; one source still shows the old ₹2,50,000.
  • TDS code 1029 (194 dividend): threshold ₹10,000; one source still shows the old ₹5,000.
